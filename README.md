# PixelVista

Static Web Technology learning portal for lab demonstration.

Topics: HTML, CSS, JavaScript, DHTML, XML/XSD/XSLT, Servlets, Session Tracking, JSP, JDBC, Quiz and Certification.

## Free GitHub Pages hosting
1. Create a GitHub account.
2. Create a new public repository named `pixelvista`.
3. Upload everything in this folder, including `index.html` and `assets`.
4. Repository → Settings → Pages.
5. Under Build and deployment choose `Deploy from a branch`.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide your public `github.io` URL.

## Payments
The certificate page contains a demo checkout only. For real paid certification, connect a payment gateway such as Razorpay/Stripe through a secure backend. Do not expose secret keys in browser JavaScript.
